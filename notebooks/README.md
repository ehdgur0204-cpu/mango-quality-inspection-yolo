# notebooks 폴더 안내

이 폴더는 실험과 분석 과정에서 사용하는 Jupyter Notebook을 보관한다.
노트북은 탐색적 분석과 빠른 실험에 사용하고, **반복적으로 재사용되는 코드는
정리하여 `src/` 아래의 적절한 패키지로 옮긴다.**

## 예정된 노트북 실행 순서

```text
01_dataset_validation.ipynb   # 이미지-라벨 대응, 좌표 범위, 클래스 번호 등 데이터 검증
02_eda.ipynb                  # 클래스 분포, 이미지 특성 등 탐색적 데이터 분석(EDA)
03_baseline_yolo.ipynb        # YOLO 베이스라인 모델 학습 및 평가
04_model_improvement.ipynb    # 데이터/하이퍼파라미터 개선을 통한 모델 성능 향상
05_error_analysis.ipynb       # 오검출·미검출 사례 분석 및 모델 신뢰성 점검
```

각 노트북은 위 번호 순서대로 실행하는 것을 기본 흐름으로 한다.
현재 이 폴더에는 아직 실제 노트북 파일이 생성되어 있지 않으며,
프로젝트 진행에 따라 순차적으로 추가될 예정이다.
