# 프로젝트 기획서 (Project Plan)

> 이 문서는 프로젝트 진행에 따라 계속 업데이트되는 문서 틀(template)이다.
> 아직 실제 성능값, 비용 절감 수치 등 실험/운영 결과는 존재하지 않으므로
> 임의의 수치를 기재하지 않는다.

## 1. 프로젝트 배경

- (작성 예정) 망고 원물 입고검사 현장에서 발생하는 문제 상황과 배경을 정리한다.

## 2. 비즈니스 문제

- (작성 예정) 현재 수작업 품질검사 과정에서 발생하는 비효율, 일관성 부족 등
  해결하고자 하는 비즈니스 문제를 정리한다.

## 3. 프로젝트 목표

- YOLO 기반 객체 탐지를 통해 망고 개체별 병해 상태를 자동 판정한다.
- 탐지 결과를 PASS / HOLD / REJECT 품질 판정 기준으로 변환한다.
- 촬영 환경 변화에 따른 모델 신뢰성을 검증한다.
- LOT 단위 품질 리포팅 체계를 구축한다.

## 4. 기대 효과

- (작성 예정) 검사 속도, 일관성, 인력 부담 등 측면에서 기대되는 효과를 정리한다.
  실제 수치는 검증 이후 기재한다.

## 5. 주요 KPI (후보)

아래는 프로젝트에서 추적할 KPI 후보 목록이다. 실제 측정값은 모델 학습 및
검증 이후 채워 넣는다.

- 병해 망고 Recall (병해를 병해로 정확히 탐지하는 비율)
- 오통과율 (병해 망고를 PASS로 잘못 판정하는 비율)
- 정상 망고 오제외율 (정상 망고를 REJECT/HOLD로 잘못 판정하는 비율)
- HOLD 비율 (전체 검사 중 재검사가 필요한 비율)
- LOT 병해율 (LOT 내 병해 개체 비율)
- 이미지당 평균 추론시간

## 6. 팀 역할 분담

- (작성 예정) 팀원별 담당 역할(데이터, 모델링, 대시보드, 문서화 등)을 정리한다.

## 7. 일정

- (작성 예정) 마일스톤 및 일정 계획을 정리한다.

## 8. 예상 위험요인

- (작성 예정) 데이터 불균형, 클래스 편향, 촬영 환경 다양성 부족 등
  예상되는 위험요인을 정리한다.

## 9. 현재 진행 상태

- 프로젝트 초기 구조 및 데이터 준비 단계
