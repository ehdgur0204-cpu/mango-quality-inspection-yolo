# outputs 폴더 안내

이 폴더는 발표나 보고서 등에 사용할 **대표 결과물**을 정리해 보관하는 곳이다.
YOLO 학습/평가 과정에서 자동으로 생성되는 전체 결과(로그, 체크포인트,
중간 산출물 등)는 `runs/` 폴더에 저장되며, `runs/`는 `.gitignore`에 등록되어
Git에서 제외된다.

즉, `runs/`는 실험 과정에서 생기는 원본 결과 전체를 담는 임시 작업 공간이고,
`outputs/`는 그중 발표·보고서용으로 선별한 대표 결과만 옮겨 담는 곳이라는
원칙을 따른다.

## 하위 폴더 역할

- **`figures/`**: 발표 및 보고서에 사용할 그래프, 시각화 이미지 등을 저장한다.
- **`metrics/`**: 모델 평가지표(정확도, Recall, mAP 등) 요약 결과를 저장한다.
- **`predictions/`**: 대표 이미지에 대한 YOLO 탐지 결과(시각화된 예측 이미지 등)를
  저장한다.
- **`reports/`**: 최종적으로 생성된 CSV/PDF 품질검사 보고서를 저장한다.
