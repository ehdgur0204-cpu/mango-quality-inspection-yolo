# tests 폴더 안내

이 폴더는 향후 작성할 자동화 테스트를 보관한다. 현재는 테스트 코드가 아직
작성되지 않았으며, 아래는 앞으로 검증해야 할 항목 목록이다.

## 검증 예정 항목

- 이미지 파일과 라벨 파일의 파일명이 서로 일치하는지 (짝이 맞는지) 확인
- YOLO 라벨의 좌표 값이 0~1 범위 안에 있는지 확인
- 라벨의 클래스 번호가 0~3 범위(4개 클래스) 안에 있는지 확인
- 기준 미만의 Confidence를 가진 탐지 결과가 HOLD로 판정되는지 확인
- Healthy 객체가 조건을 충족할 때 PASS로 판정되는지 확인
- 병해 클래스(Alternaria, Anthracnose, Scab) 객체가 조건을 충족할 때
  REJECT로 판정되는지 확인
